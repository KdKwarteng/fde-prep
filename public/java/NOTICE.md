# Third-party files in this folder

- `ecj.jar` is the Eclipse Compiler for Java 3.42.0 (`org.eclipse.jdt:ecj:3.42.0` from Maven Central), distributed under the [Eclipse Public License 2.0](https://www.eclipse.org/legal/epl-2.0/). Source: https://github.com/eclipse-jdt/eclipse.jdt.core. It is used only if the in-browser Java runtime has no built-in `javac`.
- `harness.jar` is built from `java/src` in this repository by `scripts/build-java-harness.sh`.
